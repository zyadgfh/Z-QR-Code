## 1) تقييم المشروع (حقائق موثقة)

**المنتج**: منيو وطلبات QR لـ SaaS للمحلات الصغيرة (مطاعم/كافيهات) — السوق الضمني: مصر/العالم العربي.
**المكدس**: React 18 + Vite + zustand + GSAP + qrcode · Express 4 + Node 26 · Firebase Firestore + Storage · JWT (HS256 + scrypt) · نشر Vercel (api/index.js) + Render (server/index.js) · Gemini 3.5 Flash-Lite للخادم فقط.
**المرحلة**: v1 مكتملة ومنشورة إنتاجيًا على https://qr-menu-psi-two.vercel.app — جاهزة لأول محلات حقيقية.
**الاختبارات**: 9 ملفات، 34 اختبارًا، كلها ناجحة · لا CI · لا اختبارات E2E.
**الحجم**: حزمة العميل 392KB (gzip 135KB) غير مقسّمة · الخادم ~1550 سطرًا.

- الفائدة: وصول الطلب فوري؛ رسوم قراءات أقل؛ تجربة «مباشر» حقيقية.
- الاعتماديات: صلاحيات قراءة Firestore للوحة أو مسار SSE بالخادم · مخاطر: إدارة اتصالات على serverless (يفضّل listeners مباشرة).
- القبول: يظهر طلب جديد < 1s بدون استقصاء؛ تراجع قراءات Firestore ≈ 60%.
